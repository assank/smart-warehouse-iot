# Умный склад: ESP32 в Wokwi, 3D-модель и двусторонний MQTT

Цифровой двойник сортировочного конвейера. Посылки едут по ленте, ESP32 выбирает лоток A/B/C, сервоприводы-заслонки сбрасывают их, при заторе лента останавливается. 3D-сайт показывает всё это и умеет управлять платой.

## Быстрый запуск

1. Откройте `index.html` в Chrome, Edge или Safari. Всё работает без интернета: в файл встроены Three.js, OrbitControls и MQTT.js.
2. Нажимайте сценарии справа: «Час пик», «Затор», «Сбой датчика веса», «Аварийный стоп». Кликайте по лоткам и красной кнопке прямо в 3D.
3. Ползунки «Вес» и «Температура» работают в демо-режиме.

## Подключение настоящей платы (Wokwi)

1. Откройте [wokwi.com](https://wokwi.com), создайте проект **ESP32** (DevKit V1).
2. Вставьте файлы из папки `wokwi/`: `sketch.ino`, `diagram.json`, `libraries.txt`. На сайте под «Файлы для Wokwi» есть кнопки, которые показывают их содержимое для копирования.
3. Нажмите зелёную кнопку ▶. На бесплатном тарифе компиляция может ждать в очереди. Дождитесь подключения к Wi-Fi `Wokwi-GUEST`.
4. На сайте нажмите «Подключить Wokwi». Когда в углу появится «ESP32 / Wokwi», модель показывает состояние платы, а кнопки сценариев отправляют ей команды.
5. «Вернуться в демо» переключает сайт на встроенную копию логики.

## Что на плате

| Компонент | Пин | Назначение |
|---|---|---|
| Потенциометр | D34 | вес посылки, 0–50 кг |
| DHT22 | D4 | температура склада |
| Сервоприводы A/B/C | D18 / D19 / D23 | заслонки-сбрасыватели |
| Кнопки A/B/C | D25 / D26 / D27 | работник освобождает лоток |
| Красная кнопка STOP | D14 | аварийный стоп (нажатие переключает) |
| Светодиод BELT (зелёный) | D13 | лента едет |
| Светодиод ALARM (красный) | D15 | авария |
| Зуммер | D32 | сигнал при аварии |
| OLED SSD1306 | D21 / D22 (I2C) | статус |

## Как работает логика

- Шаг 100 мс. Лента длиной 1000 условных единиц, посылка проходит её за 10 с.
- Заслонки на позициях 250, 500, 750. Посылка со своим лотком сбрасывается заслонкой.
- Вес посылки плюс случайная прибавка 0–4 кг. Больше 40 кг, либо датчик веса сломан: посылка проезжает мимо всех заслонок в корзину брака.
- В лотке 5 мест. Когда посылка приезжает к полному лотку, лента останавливается (`FULL:X`) и ждёт, пока работник освободит лоток.
- Аварийный стоп останавливает ленту и поступление посылок. Температура 30 °C и выше даёт предупреждение `HOT`.
- Если посылки некуда класть (лента занята), растёт счётчик «Не принято на вход».
- Приоритет аварий: `ESTOP`, `FULL`, `FAULT`, `HOT`.

## Команды (Serial Monitor Wokwi и MQTT)

`normal`, `rush`, `idle`, `jam`, `clear`, `clra`, `clrb`, `clrc`, `fault`, `fixed`, `estop`, `release`

Топики MQTT (публичный брокер HiveMQ, TCP 1883 у платы, WSS 8884 у сайта):
- `smartwarehouse/sw-3f9a2c71/state`: JSON каждые 0,5 с
- `smartwarehouse/sw-3f9a2c71/command`: текстовые команды

Если несколько человек запускают копии одновременно, поменяйте `sw-3f9a2c71` в `sketch_main.cpp` и `app.js`.

## Что внутри

- `index.html`: готовый сайт (собирается скриптом).
- `wokwi/`: `sketch.ino`, `diagram.json`, `libraries.txt`.
- `src/controller.js` и `src/Controller.h`: одна и та же логика на JS (сайт) и C++ (плата).
- `src/app.js`, `src/shell.html`: 3D-сцена и интерфейс. `src/sketch_main.cpp`: Arduino-часть.
- `tests/`: проверки логики.
- `ЗАЩИТА.md`: последовательность показа и ответы на вопросы.

## Сборка и тесты

```sh
python3 tools/build.py        # собирает wokwi/sketch.ino и index.html
node tests/test_controller.mjs
mkdir -p .build
c++ -std=c++17 tests/test_controller.cpp -o .build/tc
.build/tc > .build/cpp.txt
node tests/test_controller.mjs trace > .build/js.txt
diff .build/js.txt .build/cpp.txt && echo "JS и C++ совпадают"
```

Последняя пара команд сравнивает 170 контрольных точек сценария на 1700 шагов в JS и C++: результат должен быть побайтно одинаковым.

## Границы версии (честно)

- Это симуляционный прототип. Физического макета нет.
- Сканера штрихкодов нет: лоток выбирается псевдослучайно, вес задаёт потенциометр.
- Движение в 3D показывает состояние платы, это не физика.
- MQTT идёт через общий публичный брокер без логина, а плата подключается без TLS. В канале только демонстрационные данные. Для боевого варианта нужен свой брокер с авторизацией и TLS.
- Прошивка проверена на синтаксис и совпадение логики с JS, но компиляцию и запуск в Wokwi нужно сделать самому. Если Wokwi покажет ошибку библиотеки или пина, присылайте текст ошибки.
- Нет истории в базе данных и Telegram-уведомлений. Это естественное следующее расширение.
